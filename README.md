# 🛴 서울과기대 이동수단 규정 안내 챗봇

서울과학기술대학교 교내 이동수단 관련 규정을 자연어로 질문하면 관련 조항을 찾아주는 RAG 기반 챗봇입니다.

## 📌 주요 기능

- 교내 **개인형 이동장치(전동킥보드 등) 안전관리 규정** 검색
- 교내 **캠퍼스 교통관리(주차) 규정** 검색
- 답변과 함께 **참조된 원본 문서 조항** 표시
- 카테고리별 **예시 질문** 제공으로 빠른 탐색 지원

## 🏗️ 기술 스택

| 역할 | 기술 |
|------|------|
| LLM | Azure OpenAI (GPT-4o mini) |
| 검색 | Azure AI Search (Semantic + Vector Hybrid) |
| 임베딩 | Azure OpenAI Embeddings |
| 프론트엔드 | Streamlit |
| 배포 | Streamlit Cloud |
